# BUG-001: XSS Vulnerability in Search Results

## Bug Information

| Field | Value |
|-------|-------|

| **Severity** | High |
| **Status** | Open |
| **Reported By** | 23127053 |
| **Date** | 2026-08-11 |

## Description

The search functionality in the EShop homepage has a potential XSS (Cross-Site Scripting) vulnerability. When a user enters HTML/JavaScript code in the search input, the search results section renders the search keyword using `dangerouslySetInnerHTML`, which can execute arbitrary JavaScript code.

## Steps to Reproduce

1. Navigate to `http://localhost:5173`
2. Enter `<script>alert("xss")</script>` in the search input field
3. Click the "Tìm" (Search) button
4. Observe that the search keyword is rendered in the results section

## Expected Result

The search keyword should be safely escaped and displayed as plain text, not executed as HTML/JavaScript.

## Actual Result

The search keyword is rendered using `dangerouslySetInnerHTML`, which may execute the injected script.

## Code Location

**File:** `frontend-web/src/pages/Home.jsx`
**Line:** 64

```jsx
<span dangerouslySetInnerHTML={{ __html: search }} />
```

## Impact

- An attacker could inject malicious scripts that steal user session tokens
- Could lead to account takeover or data theft
- Violates security best practices (SEC-04: UI data must be properly escaped)

## Suggested Fix

Replace `dangerouslySetInnerHTML` with safe text rendering:

```jsx
<span>{search}</span>
```
