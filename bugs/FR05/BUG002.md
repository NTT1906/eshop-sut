# BUG-002: Price Display Uses VND Instead of ₫ Symbol

## Bug Information

| Field | Value |
|-------|-------|
| **Bug ID** | BUG-002 |
| **Feature** | FR-05: Product Listing and Search |
| **Severity** | Low |
| **Status** | Open |
| **Reported By** | 23127053 |
| **Date** | 2026-08-11 |

## Description

The product listing page displays prices using "VND" as the currency unit instead of the Vietnamese Dong symbol "₫" as specified in the requirements.

## Steps to Reproduce

1. Navigate to `http://localhost:5173`
2. Observe the price display on product cards

## Expected Result

Prices should be displayed with the "₫" symbol (e.g., "250,000 ₫")

## Actual Result

Prices are displayed with "VND" (e.g., "250,000 VND")

## Code Location

**File:** `frontend-web/src/pages/Home.jsx`
**Line:** 88

```jsx
<p className="text-red-500 font-bold mb-2">
  {Number(p.price).toLocaleString()} VND
</p>
```

## Impact

- Does not comply with FR-21: "Luôn dùng ký hiệu ₫ với định dạng phân cách hàng nghìn"
- Minor UI inconsistency

## Suggested Fix

Change "VND" to "₫":

```jsx
<p className="text-red-500 font-bold mb-2">
  {Number(p.price).toLocaleString()} ₫
</p>
```
