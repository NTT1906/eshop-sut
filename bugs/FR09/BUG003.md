# BUG-003: Incorrect Coupon Discount Calculation for Percent Type

## Bug Information

| Field | Value |
|-------|-------|
| **Bug ID** | BUG-003 |
| **Feature** | FR-09: Discount Coupons |
| **Severity** | High |
| **Status** | Open |
| **Reported By** | 23127053 |
| **Date** | 2026-08-11 |

## Description

The coupon discount calculation for percent-type coupons is incorrect. The system calculates `discount_amount = total × (1 - discount_value)` instead of `discount_amount = total × discount_value / 100`.

## Steps to Reproduce

1. Login as user `test@eshop.com`
2. Add a product worth 500,000 ₫ to cart
3. Go to checkout
4. Apply coupon code "SAVE10" (10% discount)
5. Observe the discount amount

## Expected Result

- discount_amount = 500,000 × 10 / 100 = 50,000 ₫
- final_amount = 500,000 - 50,000 = 450,000 ₫

## Actual Result

- discount_amount = 500,000 × (1 - 10) = 500,000 × (-9) = -4,500,000 ₫
- final_amount = 500,000 - (-4,500,000) = 5,000,000 ₫

## Code Location

**File:** `backend/server.js`
**Line:** 399-401

```javascript
if (coupon.type === "percent") {
  discount_amount = Math.floor(
    total_amount * (1 - coupon.discount_value),
  );
}
```

## Impact

- All percent-type coupons calculate incorrect discount amounts
- Users may get negative discounts or extremely large final amounts
- Business logic violation of FR-09 requirements

## Suggested Fix

Change the calculation formula:

```javascript
if (coupon.type === "percent") {
  discount_amount = Math.floor(
    total_amount * coupon.discount_value / 100,
  );
}
```
