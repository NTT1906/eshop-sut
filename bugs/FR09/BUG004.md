# BUG-004: Admin Dashboard Revenue Calculation Multiplies by 2

## Bug Information

| Field | Value |
|-------|-------|
| **Bug ID** | BUG-004 |

| **Severity** | Medium |
| **Status** | Open |
| **Reported By** | 23127053 |
| **Date** | 2026-08-11 |

## Description

The admin dashboard revenue calculation incorrectly multiplies the total amount by 2 when summing delivered orders.

## Steps to Reproduce

1. Login as admin `admin@eshop.com`
2. Navigate to Dashboard
3. Observe the total revenue calculation

## Expected Result

Total revenue should be the sum of `total_amount` for all delivered orders.

## Actual Result

The calculation multiplies each order's `total_amount` by 2:

```javascript
const totalRevenue = orders.reduce((sum, o) => {
  if (o.status === "delivered") return sum + o.total_amount * 2;
  return sum;
}, 0);
```

## Code Location

**File:** `frontend-admin/src/App.jsx`
**Line:** 217-220

```javascript
const totalRevenue = orders.reduce((sum, o) => {
  if (o.status === "delivered") return sum + o.total_amount * 2;
  return sum;
}, 0);
```

## Impact

- Dashboard displays incorrect revenue figures
- May mislead business decisions
- Does not comply with FR-13 requirements

## Suggested Fix

Remove the multiplication by 2:

```javascript
const totalRevenue = orders.reduce((sum, o) => {
  if (o.status === "delivered") return sum + o.total_amount;
  return sum;
}, 0);
```
