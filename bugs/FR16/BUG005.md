# BUG-005: CSV Import Does Not Validate Price as Positive Number

## Bug Information

| Field | Value |
|-------|-------|
| **Bug ID** | BUG005 |
| **Feature** | FR-16: Product Import from CSV |
| **Severity** | Medium |
| **Status** | Open |
| **Reported By** | 23127053 |
| **Date** | 2026-08-11 |

## Description

The CSV import functionality does not validate that the price field contains a positive number. Products with negative prices or non-numeric prices can be imported.

## Steps to Reproduce

1. Login as admin `admin@eshop.com`
2. Navigate to Products tab
3. Upload a CSV file with negative price values
4. Click Import

## Expected Result

The system should reject products with negative prices and display validation errors.

## Actual Result

Products with negative prices are imported successfully without any validation errors.

## Code Location

**File:** `backend/server.js`
**Line:** 213-232

The import endpoint does not validate that `price > 0`:

```javascript
rows.forEach((row, index) => {
  if (!row.name) {
    errors.push(`Hàng ${index + 2}: Thiếu tên sản phẩm`);
    return;
  }
  // Missing: if (row.price <= 0) { errors.push(...); return; }
  stmt.run(row.name, row.price, ...);
});
```

## Impact

- Products with invalid prices can be added to the database
- May cause issues with pricing calculations
- Violates FR-16 requirements: "price phải là số dương"

## Suggested Fix

Add price validation:

```javascript
rows.forEach((row, index) => {
  if (!row.name) {
    errors.push(`Hàng ${index + 2}: Thiếu tên sản phẩm`);
    return;
  }
  if (!row.price || isNaN(row.price) || Number(row.price) <= 0) {
    errors.push(`Hàng ${index + 2}: Giá phải là số dương`);
    return;
  }
  stmt.run(row.name, row.price, ...);
});
```
