## BVA Scope

BVA is applied only to variables with numeric, length-based, date, or ordered boundaries.

| Variable | BVA Decision | Reason |
|----------|--------------|--------|
| `email` | Excluded | Required field exists, but no explicit minimum length, maximum length, or format boundary is specified in the UI/API evidence. Account existence is a domain partition, not an ordered boundary. |
| `resetToken` | Included as confirmation-needed | UI label says `Mã OTP (4 số)`, which implies exactly 4 digits. However, API example shows 6 digits and DOM has no `minlength`, `maxlength`, or `pattern`. |
| `newPassword` | Included | Visible password rule states minimum length 8 and at least one uppercase, lowercase, digit, and special character. No maximum length is specified. |
